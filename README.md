# Vision-Based Waste Classification

A deep learning-based waste classification research project designed to classify waste images into 36 categories using DP-CNN, Res-CBAM, and an Ensemble Extreme Learning Machine (En-ELM).

## Project Overview

Proper waste classification is an important step towards efficient waste management and recycling. This project explores a deep learning approach to automatically identify different types of waste from images.

The proposed approach combines a DP-CNN architecture with Res-CBAM attention and an Ensemble ELM classifier.

## Key Features

- 36-class waste image classification.
- DP-CNN architecture using depthwise separable convolutions.
- Res-CBAM attention mechanism to enhance feature representation.
- Ensemble ELM classification approach.
- Image preprocessing and data augmentation.
- Grad-CAM-based model explainability.
- Waste disposal and recycling recommendation interface.
